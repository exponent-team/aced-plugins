# Aced for ChatGPT

Prep for interviews with [Aced](https://www.aced.io) inside ChatGPT and Codex. The plugin
connects to Aced's interview data: real questions that candidates reported, verified
interview experiences, expert-written company guides, and courses. Every answer links back
to its source on Aced, so you know you're practicing with real questions.

## What it does

| Skill | Use it when |
|---|---|
| `prep-from-jd` | You have a job description. Paste it in, or paste the posting URL, and get a study plan for that company and role, built from Aced data with every source linked. |

## Install

Add the marketplace in Codex:

```
codex plugin marketplace add exponent-team/aced-plugins
```

Then install **Aced** from the plugin directory in the ChatGPT desktop app or Codex.

## Connecting

The plugin adds the Aced connector (`https://www.aced.io/api/mcp`). You can search and read
free content without signing in. Members-only lessons, guides and interview reports ask you
to sign in to Aced, and they unlock with an active Aced membership.
